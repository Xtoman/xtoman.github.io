Glitch

Real glitches only: the image data is actually damaged and then read back. Nothing leaves your browser.

Add a step

How it works

  • Audio — the raw pixel bytes are treated as a sound recording, run through an audio effect (echo, reverb, phaser, wah…) and written back as pixels. The same trick as importing an image into an audio editor.
  • JPEG — the image is saved as a real JPEG, random bytes of the compressed stream or its quantization tables are overwritten, and the browser's decoder shows whatever it can still read.
  • PNG filters — scanlines are run through PNG prediction filters, the filtered data is damaged, then decoded. Each filter spreads the damage in its own way.
  • Raw misread — the pixel data is intact, but read with the wrong width, offset or channel layout, as if the file header lied.

Steps run top to bottom, each one feeding the next. Results depend on the working size, because the data itself changes.
